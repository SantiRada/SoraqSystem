# Soraq — Internacionalización (i18n)

> Soraq es **nativo en español** ([ADR 0008](decisions/0008-spanish-native-i18n.md)). Esta guía explica cómo se escriben textos hoy y cómo agregar otro idioma.

## 1. Reglas para escribir textos

1. **Ningún texto visible inline** en componentes: siempre `t('namespace.clave')`.
2. **Frases completas** en el catálogo; nunca concatenar fragmentos (el orden de las palabras cambia entre idiomas). Usar parámetros: `'Actualizado {time}'`.
3. **Plurales** con objeto `{ one, other }` (opcional `zero`) y `{count}`.
4. Fechas, números y dinero con `shared/i18n/format.ts` (Intl), nunca a mano.
5. Aria-labels, títulos de página, mensajes de error y textos alternativos también se traducen.
6. Slugs de URL, ids y códigos (`validation_failed`) **no** se traducen.
7. Español **neutro con tuteo** ("Crea tu cuenta"). Voz y tono: [BRAND.md](BRAND.md#5-voz-y-tono).
8. Términos de la disciplina UX que el mercado usa en inglés se mantienen (Card Sorting, Design System, Handoff).

## 2. Frontend

```
frontend/src/i18n/
├── config.ts           locales soportados (es) + metadatos (htmlLang, ogLocale)
├── types.ts            Messages (derivado del catálogo es), MessageKey, PluralMessage
├── translate.ts        createTranslator(): interpolación {param} + plurales (Intl.PluralRules)
├── I18nProvider.tsx    contexto, <html lang>, I18nProvider de React Aria
├── I18nContext.ts      useI18n()
├── index.ts            API pública
└── locales/es/         UN ARCHIVO POR NAMESPACE (≈ feature)
    ├── common.ts       acciones, a11y, tema, errores genéricos, meta
    ├── auth.ts  projects.ts  workspace.ts  system.ts  marketing.ts
    └── index.ts        combina namespaces → `messages`
```

Uso:
```tsx
const { t, locale } = useI18n();
t('projects.list.title');                          // "Proyectos"
t('projects.list.count', { count: 3 });            // "3 proyectos"
t('workspace.sectionPage.comingSoonTitle', { section: 'Brief' });
```

- `MessageKey` es un tipo: una clave inexistente es **error de compilación**.
- Claves dinámicas deben seguir tipadas: `` t(`workspace.items.${id}`) `` solo si `id` es una unión de literales; si no, guardar la `MessageKey` en los datos (ver `projectNavigation.ts`).
- ESLint prohíbe importar `@/i18n/locales/*` fuera de `src/i18n`.
- Nuevo feature ⇒ nuevo archivo `locales/es/<feature>.ts` + registrarlo en `locales/es/index.ts`.

## 3. Backend

```
backend/lang/es/errors.php       mensajes de error del API
backend/lang/es/validation.php   mensajes por regla (:min, :max)
backend/src/Core/I18n/Translator.php
```

- `HttpException` recibe **claves** (`'errors.project_not_found'`), `Validator` produce `[clave, params]`.
- `Application` negocia el idioma con `Accept-Language` entre `config/app.php → supported_locales` (default `APP_LOCALE`) y responde `Content-Language`.
- El cliente envía `Accept-Language` = `<html lang>` (`shared/api/httpClient.ts`).
- Clave faltante ⇒ idioma por defecto ⇒ la propia clave.

## 4. Agregar un idioma (ej. inglés)

1. **Frontend:** copiar `src/i18n/locales/es/` → `locales/en/` y traducir. Declarar el catálogo como `Messages`:
   ```ts
   import type { Messages } from '../../types';
   export const messages: Messages = { … };   // TypeScript marca claves faltantes o sobrantes
   ```
2. Registrar en `src/i18n/config.ts`: `en: { label: 'English', htmlLang: 'en', ogLocale: 'en_US' }`.
3. `I18nProvider`: cargar el catálogo del locale activo (import dinámico por locale) y decidir el locale (preferencia en `users.locale`, luego `navigator.language`, luego `es`).
4. Agregar un selector de idioma (ej. en el menú de cuenta) que actualice `users.locale` (endpoint nuevo ⇒ auditoría).
5. **Backend:** copiar `lang/es` → `lang/en`, traducir, agregar `'en'` a `supported_locales`.
6. **SEO:** `hreflang` por página pública, `og:locale`, sitemap por idioma (ver [SEO.md](SEO.md)).
7. Revisar layouts con textos más largos (+30–40%).

No hace falta tocar componentes: todos leen de `t()`.

## 5. Checklist de revisión
- [ ] Sin strings visibles hardcodeados (buscar comillas con letras en `.tsx` fuera de `i18n/`).
- [ ] Sin concatenaciones de frases.
- [ ] Plurales con `{count}`.
- [ ] Mensajes nuevos del API con clave en `backend/lang/es`.
